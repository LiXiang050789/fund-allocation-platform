## 前言：怎么用这份手册

这不是一份"计划表"，而是一份"照着做就能完成"的操作手册。每个任务都包含：

- **目标**：这个任务要实现什么
- **输入/输出**：需要什么数据、产出什么文件
- **具体步骤**：Step by Step，包含代码示例和参数说明
- **验收标准**：怎么判断做对了
- **常见坑点**：容易犯的错和解决方法

### 协作核心规则（解决晚间时间冲突）

1. **异步交接机制**：当日上游产出上传共享盘，下游次日晚间开发使用。当日A、B无依赖时并行干活，不会卡住。
2. **每日10:00线上短会（≤15min）**：C同步当日产出、前一晚A/B各自进度，仅同步不现场开发。
3. **统一文件规范**：`名称_YYYYMMDD_HHMM.csv`，共享盘根目录C每日更新README，标注最新有效文件。
4. **时序铁则**：先统一交易日历锚定时间，滚动窗口仅训练集标准化，**禁止全量归一化泄露**。
5. **奖励规则**（如用PPO）：Env只用日收益做即时奖励，年化/夏普仅离线回测指标。
6. **本周边界**：增量素材只下载归档、不清洗、不并入本周训练集，留给SAC二期。

```python
# 估值维度（25分）- PE分位数越低越便宜，得分越高
def val_score(pe_pct, pb_pct, erp_pct):
    s = (1-pe_pct)*40 + (1-pb_pct)*30 + erp_pct*30
    return np.clip(s, 0, 25)

# 宏观维度（25分）
def macro_score(pmi, m1_m2, sf_g, bs):
    s = np.clip((pmi-48)/4, 0, 1)*7      # PMI: 48~52
    s += np.clip((m1_m2+5)/10, 0, 1)*6   # M1-M2: -5~5
    s += np.clip(sf_g/15, 0, 1)*6         # 社融: 0~15%
    s += np.clip(bs/1, 0, 1)*6            # 利差: 0~1%
    return np.clip(s, 0, 25)

# 情绪维度（20分）
def sent_score(margin_chg, north_30d, vol20):
    s = np.clip(margin_chg/0.1, -1, 1)*7
    s += np.clip(north_30d/500, -1, 1)*7
    s += np.clip((0.25-vol20)/0.2, 0, 1)*6
    return np.clip(s+10, 0, 20)

# 趋势维度（30分，权重最高）
def trend_score(ma20_slope, above_days, macd):
    s = np.clip(ma20_slope/0.02, -1, 1)*10
    s += np.clip(above_days/20, -1, 1)*10
    s += 10 if macd > 0 else 0
    return np.clip(s+15, 0, 30)

# 合成总分并映射状态
df['total_score'] = df['val_score'] + df['macro_score'] + df['sent_score'] + df['trend_score']
# 使用 np.select 分类（比嵌套 if 更清晰）
```

```python
def calc_all_metrics(returns, weights=None):
    """完整风险指标套件"""
    ann_ret = returns.mean() * 252
    ann_vol = returns.std() * np.sqrt(252)
    sharpe = ann_ret / ann_vol
    sortino = ann_ret / (returns[returns<0].std() * np.sqrt(252))  # 索提诺
    max_dd = (returns.cumsum().expanding().max() - returns.cumsum()).max()  # 最大回撤
    calmar = ann_ret / max_dd
    turnover = (weights.diff().abs().sum(axis=1).mean()) if weights is not None else None  # 换手率
    concentration = (weights**2).sum(axis=1).mean() if weights is not None else None  # 权重集中度(HHI)
    return {
        '年化收益': ann_ret, '年化波动': ann_vol,
        '夏普': sharpe, '索提诺': sortino,
        '最大回撤': max_dd, '卡玛': calmar,
        '日均换手': turnover, '权重集中度HHI': concentration
    }
```
