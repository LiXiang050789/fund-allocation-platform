## 2. 评分系统（与代码一致）

- 四维权重：估值 25 + 宏观 25 + 情绪 20 + 趋势 30 = 100
- 五状态阈值：**≥75 上行 / 60-74 震荡偏强 / 45-59 震荡 / 30-44 下行 / <30 极寒**（`calc_market_score.py`）
- 各维度规则：估值=沪深300 PE 5年分位（30%/70% 阈值线性）；宏观=PMI(15分)+10Y-2Y利差(10分)；情绪=两融月变化率(10分)+北向月净流入(10分)；趋势=沪深300收盘 vs MA20 偏离度(30分)
- `market_score_clean.csv` 与 `market_score_daily.csv` 当前完全一致（corr=1.0，状态一致 100%）

## 11. 审查方法与输出格式

收到 cc 结论后逐条输出：

- 【正确】：与上述基准/脚本/CSV 一致，给出依据（文件+数值）。
- 【需修正】：数据不一致或口径错误，给出正确值及出处；最终意见含"撤回/修改"。
- 【遗漏】：未考虑维度或反例，例如：
  - PPO 是否忽略"独立引擎、成本假设不可比"前提；
  - 引用全期指标是否与"年费已扣、修正后版本"一致；
  - 特征数/阈值是否踩 37/42/44、0.022/0.015 的口径坑；
  - 是否引用 94.3% 敏感性、+0.5% MVO 等已过时数字；
  - 是否混淆"危机累计收益"与"窗口内回撤"；
  - "X 优于 Y"是否漏了样本外/成本/可比性前提。
- 最终结论：明确【撤回 / 保留 / 修改】。

## 复核方法（重建本基准的方式）

1. 指标复算：`sys.path.insert(0,'fund-platform/scripts')` → `portfolio_metrics.calc_portfolio_metrics(nav_series)`（年化=(1+累计)^(252/len)-1，夏普=年化/波动，无风险利率不扣）。
2. 评分权重/阈值：读 `calc_market_score.py` 四个 calc_* 函数与状态映射。
3. 成本：读 `backtest_baselines.py` SLIPPAGE/FEE/ANNUAL_FEE 与扣费逻辑。
4. 敏感性复现：`python3 fund-platform/scripts/sensitivity_analysis.py`（当前输出 92.6%）。
5. 特征数：`train_feature_filtered.csv` 列数（38 含 date）。
6. PPO 复现：对 `global_ppo_net.csv` 与 `PPO_rolling_detailed.csv` 分别调用 `calc_portfolio_metrics`。
