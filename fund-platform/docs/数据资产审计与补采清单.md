### 8.2 `强化学习.txt` —— PPO 方案设计文档

内容结构（详见原文）：

1. **特征工程**：172 维 → 3σ 去噪 → IC 筛选 → 共线性剔除 → LightGBM 重要性二次验证 → 精炼特征集
2. **自定义交易环境（Env）**：状态 = 市场特征 + 持仓权重 + 组合净值；动作 = Softmax 归一化 7 资产权重；奖励 = 日收益 + 波动惩罚 + 回撤惩罚 + 换手惩罚（历史滚动窗口计算，无未来泄露）
3. **滚动窗口训练**：500 天训练窗 → 60 天预测窗，验证集夏普早停
4. **消融实验**：PPO vs A2C vs DDPG，论证"实验证明 PPO 最适合金融资产配置"（非随意选模型）
5. **传统基线**：等权 / 风险平价 / 动量

**用途**：这是 zt 为 PPO 路线准备的答辩技术文档，逻辑完整，可直接提取为答辩 PPT 技术页素材。根据项目方案评估建议 PPO 已被建议砍掉/降级——但**即使最终不跑 PPO，文档本身可作为"我们设计了 RL 方案但因时间聚焦 LightGBM 基线"的技术储备展示**，在答辩中展示方案思考深度。
